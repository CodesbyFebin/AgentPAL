# Security Policy

Report vulnerabilities affecting the current default branch or the hosted demo.

Use [GitHub private vulnerability reporting](https://github.com/CodesbyFebin/AgentPAL/security/advisories/new).
Include the affected commit or environment, the impact, and enough detail for the maintainer
to reproduce the issue. Remove credentials, payment identifiers, and personal information
from any logs or screenshots. Keep vulnerability details private while the maintainer investigates.
